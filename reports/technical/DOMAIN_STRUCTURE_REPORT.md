# DOMAIN STRUCTURE REPORT — Phishing AI Master 2

## 1. Analyse de la structure des domaines

Le domaine registrable est extrait en prenant les 2 derniers labels du host (ou 3 pour les suffixes multi-parties comme co.uk).

## 2. Statistiques

- Domaines registrables uniques : 96 155.
- Domaines cross-label (phishing + légitime) : 591.
- Sous-domaines moyens : 0.256 (légitimes) vs 0.534 (faux positifs).

## 3. Impact sur les faux positifs

Les faux positifs ont plus de sous-domaines (0.53 vs 0.26) et sont plus souvent sur des TLD sous-représentés (.cn, .ar, .uk, .ru).

## 4. Conclusion

La structure du domaine est un signal important mais insuffisant. Les features de réputation de domaine (Tranco rank) pourraient aider.
